Nöbet Çözücü — basit arayüz (Aşama 1)

Aşağıdaki JSON girdisini kendi servisinin verilerine göre düzenle (profil, personel, gereksinimler, izinler, kısıtlamalar), "Çöz" butonuna bas. Bu, gerçek servis kurallarını içermeyen bir örnektir — gerçek kullanım için değerleri değiştirmen gerekir.

Henüz çözüm yok.
